# Expanded source registry

The runner registry now includes national procurement portals, agencies, institutional portals, international funding/procurement portals, and discovery aggregators.

- All source entries remain disabled by default.
- Aggregators are marked non-official and are discovery-only; every lead should be verified with the original publisher.
- This is a metadata expansion, not live collection.
- Hospital, university, city-hospital and provincial-directorate URLs can be added as configured institution-specific entries after URL/access review.
- Adapters must honor public access, terms, rate limits, and avoid authentication or anti-bot bypass.
